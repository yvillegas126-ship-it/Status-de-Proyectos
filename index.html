Servicio de anotaciones
Las anotaciones se guardan en un JSON de GitHub a través de este servicio, que es quien custodia el token. Nadie se loguea ni configura nada para anotar. La URL definitiva se escribe una sola vez en index.html, en la constante ANOTACIONES_API; este campo sirve para probar otra URL solo en este navegador. El código del servicio y sus pasos de despliegue están en anotaciones-worker.js.
